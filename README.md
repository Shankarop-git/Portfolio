## 👨‍💻 About the Project

**Shankar Patil — 3D Developer Portfolio** is a modern and immersive personal portfolio website designed to present my technical skills, professional experience, projects, and development journey in an engaging way.

The portfolio combines **React, TypeScript, Tailwind CSS, Three.js, and Framer Motion** to create a premium dark-themed experience featuring interactive 3D elements, smooth animations, responsive layouts, and dynamic content.

> 💡 **Goal:** Create more than a traditional portfolio — build an interactive experience that demonstrates my passion for Full Stack Development, AI/ML, and modern web technologies.

## ⚡ Quick Start

Follow the steps below to run the portfolio locally.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Shankarop-git/3D-Developer-Portfolio.git
```

### 2️⃣ Navigate to the Project

```bash
cd 3D-Developer-Portfolio
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm run dev
```

### 5️⃣ Open in Browser

Vite will provide a local development URL, typically:

```text
http://localhost:5173
```

Open the URL in your browser and explore the portfolio. 🚀

## 📧 EmailJS Configuration

The contact form uses **EmailJS** to send messages.

To configure it:

1. Create an EmailJS account.
2. Create an email service.
3. Create an email template.
4. Obtain your EmailJS credentials.
5. Add the required credentials to your project's environment/configuration.
6. Restart the development server.

> 🔐 **Security Tip:** Never commit private API keys, secrets, or sensitive credentials to GitHub.
